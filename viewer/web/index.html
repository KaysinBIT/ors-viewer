导入三维数据

原始文件由 Python 独立解析，完成后自动显示模型。支持 .ORSSession / .ORSObject / .STL / .NPY。

ORS 支持体数据、分割、网格与测量表。NPY 轴顺序为 ZYX / TZYX，默认体素间距为 1。输出保存在所选数据目录的 imported 文件夹，原始文件保持不变。

仅在本机处理，无需 Dragonfly

首次使用 · 设置数据目录

解析结果、显示缓存和日志将保存在你选择的目录中。

建议选择空间充足的专用文件夹。升级用户可选择以前的数据目录，继续使用已有解析结果。确认前不会创建解析结果或显示缓存。

选择会保存在本机，后续无需重复设置

选择本地文件

点击文件夹进入；选中所需文件后确认。所有操作均在本机完成。

选择本地路径时不会复制原文件
