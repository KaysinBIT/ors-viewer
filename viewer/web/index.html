导入三维数据

原始文件由 Python 独立解析，完成后自动显示模型。支持 .ORSSession / .ORSObject / .STL / .NPY。

ORS 支持体数据、分割、网格与测量表。NPY 轴顺序为 ZYX / TZYX，默认体素间距为 1。输出保存在所选数据目录的 imported 文件夹，原始文件保持不变。
