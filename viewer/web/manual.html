01　快速上手

从原始文件到三维结果，再到剖面观察和数据导出。所有文件在本机处理，无需安装 Dragonfly。

启动软件

  1. 下载 Windows x64 免安装包，完整解压。保持 ORSViewer.exe 与 _internal 目录在一起，不要只复制 EXE。
  2. 双击 ORSViewer.exe 后先显示启动配置窗口，不会自动打开网页。监听端口填 0 表示自动分配，也可输入 1–65535。首次数据目录默认为程序所在文件夹，点击“选择文件夹…”可更改。
  3. 确认后点击“保存并启动服务”。看到本地网址后，再手动点击“打开三维界面”。后续启动记住上次选择；关闭网页后也可用该按钮重新打开。

完成一次查看

  1. 点击“导入文件”，默认“选择文件”，使用文件按钮选取；大文件可切换“本地文件路径”，无需手动输入路径。
  2. 点击“解析并显示”。任务完成后会自动载入数据集；在左侧选择要查看的对象。
  3. 在三维区旋转、缩放模型。右侧启用“剖面视图”，拖动角度或距离，画面会同步更新。
  4. 点击“正对剖面”使用正交投影观察截面。使用“截图”预览并点击“保存 PNG”保存当前画面，或在“数据详情”下载数据。

支持的输入

格式内容
ORSSession / ORSObject体数据、分割、三角网格、测量与元数据
STL二进制或 ASCII 三角网格
NPY三维 ZYX 或四维 TZYX 数值体数据
已有解析目录包含 decode_report.json 的 data 目录或其输出根目录
原始网格默认保留全部顶点和三角面。软件不会为了流畅性而自动简化网格。

02　界面与三维操作

左侧选择数据，中间观察模型，右侧调整参数；测量表会在三维区下方展开。

界面分区

数据列表数据集 · 搜索 · 对象
三维视图旋转 · 缩放 · 剖面 · 测量表
属性与参数显示 · 剖面 · 导出

鼠标与视角

操作作用

右键拖动三维画面平移视图

右侧显示设置

  • 不透明度：查看半透明模型；参考网格与包围盒：帮助判断方向和范围。
  • 线框显示：显示三角面的边线，适用于网格和分割表面。
  • 颜色映射：对象带有可用的逐顶点测量列时，可按测量值着色，并显示图例。
  • 窄窗口中，点击三维区右上角“参数”展开属性面板；点击关闭按钮或按 Esc 收起。
右侧面板可以上下滚动。看不到剖面、体数据或导出设置时，先向下滚动参数面板。

03　导入与数据管理

原始文件保持不变，解析输出、缓存和日志单独保存。

三种导入方式

方式使用场景
选择文件（复制到数据目录）通过浏览器文件选择框导入，在数据目录保存输入副本
本地文件路径点击“选择文件”浏览并选取原文件，直接读取，适合大文件
已有解析目录点击“选择目录”打开已有解析结果，避免重复提取

导入时需要知道

  • 本地文件浏览器可选择磁盘、进入文件夹、返回上一级和搜索当前目录。选择数据目录时还可新建文件夹；取消选择不会自动保存。
  • 文件选择方式单文件上限为 64 GiB；更大的文件使用本地路径方式。
  • 后台任务会显示等待、校验、提取和解码状态。导入完成后自动显示支持的三维对象。
  • 解析既需要输入文件空间，也需要原始记录、数值数组与缓存空间。大文件导入前应预留足够磁盘空间。
  • 软件退出会停止本地服务。尚未完成的任务不能视为成功，已有输出会保留，重新导入时会创建新的任务目录。
  • 重新启动软件会恢复成功导入的数据集。若输出目录被手动移动，可通过“已有解析目录”重新载入。

保存位置

首次数据目录默认为 ORSViewer.exe 所在文件夹；源码运行时默认为项目目录。启动窗口提供文件夹选择按钮，保存启动时检查写入权限；不可写时请选择其他文件夹。

解析结果 imported、缓存 cache、日志 logs、示例 example 和运行信息 runtime 均保存在所选目录中。Windows 偏好保存在 %LOCALAPPDATA%\ORSViewer\settings.json。升级时沿用已保存的目录，不自动搬移或删除旧数据。

需要更换端口或目录时，点击“停止服务并修改”，重新设置并启动。停止服务会中断未完成任务，已有输出保留。--choose-data-dir 忽略保存目录并重新选择；--state-dir 仅指定本次目录，未在窗口修改时不覆盖原偏好。

坐标与单位

  • ORS 体数据和分割使用已解码的体素到世界坐标矩阵。
  • NPY 默认轴顺序为 ZYX 或 TZYX，体素间距为 1；文件本身不提供本软件可读取的物理标定。
  • STL 不包含物理单位。网格坐标按输入值显示，不能直接假定为毫米。

04　整个数据集的初始姿态对齐

用于校正模型初始姿态与镜像方向：整个数据集同步变换，三切面 XYZ 轴固定。原始文件不改写。

手动旋转

  1. 载入数据集后，在参数面板顶部找到“整个数据集 · 初始姿态”。X、Y、Z 分别提供角度滑块、精确数值与 ±90° 按钮。
  2. 旋转中心为整个数据集原始空间包围盒的中心，所有网格、CT、分割对象共用一个变换。切换对象仍沿用该姿态；已有的相对配准关系保持不变。
  3. 角度按固定 X、Y、Z 顺序组合。更新时二维保留上一帧并显示状态，三维先用当前预览精度显示切片；完整结果到达后自动替换。原始分辨率保持不变。

镜像翻转

  • 勾选 X、Y、Z 镜像开关，可单独或组合翻转。先旋转，再关于经过数据集中心的固定 XYZ 平面镜像；网格、CT、分割同步。
  • 取消镜像保留旋转；“恢复原始姿态”同时清除旋转和镜像。点击“保存对齐”后重启可恢复；旧版仅旋转的设置仍可使用。

参考面或三个点自动对齐

  1. 选择目标 XY、XZ 或 YZ 平面。点击“选择参考面”后，点选三维网格或分割表面的一块三角面；使用当前显示的网格。
  2. 也可点击“选择三个点”。在三维表面选点，或在 CT 二维切面选点；需要时滚轮移动切面后继续选取。状态区显示选点进度。CT 的外包围盒不能作为参考面。
  3. 三个点不可重合或共线。点 1→2 决定面内方向，点的顺序决定法线方向。完成后自动对齐，并将对应切面移动到参考面位置。取消按钮或 Esc 可终止选取。

采样、保存与恢复

  • 对齐 CT 的二维切面使用原始体素线性插值，读数分别列出插值与邻近原始值。分割使用最近邻，保持标签 ID；二维分割切面显示全部标签。
  • 对齐只计算当前显示切面，不重写体数据。二维切面超过显示上限会明确报错，不自动降低分辨率。三维 CT 纹理仍沿用原预览精度设置。
  • 点击“保存对齐”单独保存到本机设置，下次打开同一路径的数据集恢复。恢复原始姿态后再保存，可清除已保存的对齐效果。移动解析目录后需重新保存。
  • “恢复原始姿态”将所有对象恢复原坐标；CT 回到原始体素轴切片。原文件下载与预览 PLY 导出均保持源坐标，不包含显示旋转或镜像。
此操作假定同一数据集对象已使用一致的物理坐标与单位；它不自动完成对象之间的配准，也不更改原有测量表。

05　启动配置与网页端口

默认由系统自动分配可用的本机端口，也可以设置固定端口。更改端口不会扩大网络访问范围。

在界面中设置

  1. 在桌面启动窗口填写监听端口：0 表示自动分配，1–65535 表示指定端口。数据目录使用“选择文件夹…”按钮选择。
  2. 点击“保存并启动服务”，成功后显示实际网址。程序不会自动跳转网页，请手动点击“打开三维界面”。
  3. 运行期间修改配置前，先点击“停止服务并修改”。网页右上角“端口设置”也可保存下次启动的端口，当前解析任务不受影响。

优先级与示例

方式行为
默认 / 未保存端口由操作系统自动分配可用端口
界面保存自定义端口后续正常启动时使用保存的端口
--port 8769仅本次使用 8769，优先于保存的设置
--port 0仅本次自动分配，不改写保存设置

端口不可用时

桌面模式下，端口被占用或无绑定权限会在启动窗口内提示，服务不会启动。输入其他端口或 0 后重试；无效设置不会覆盖原偏好。

无界面模式沿用已保存端口不可用时临时自动分配的行为。显式 --port 指定的端口不可用则报错，不自动换端口。所有模式仅监听 127.0.0.1。

数据与授权说明

端口偏好与数据目录选择保存在同一设置文件中，修改其中一项会保留另一项。服务只监听 127.0.0.1，选择端口不会自动改为局域网或公网监听。

页脚“独立实现说明”提供离线组件与第三方权利说明。当前版本不集成、调用或分发 Dragonfly 官方组件；数据、商标和其他第三方权利仍依据各自授权处理。

打开启动窗口和保存启动都不会自动打开网页。只有手动点击“打开三维界面”才调用浏览器；无界面命令显式传入 --open 时除外。

06　完整网格、简化与分割标签

将“原始数据”“当前显示数据”和“实际面数”区分开，便于选择适合的观察方式。

原始网格的保留比例

  1. 选择一个三角网格对象。初始保留比例为 100%，显示全部原始顶点和三角面，不进行去重或自动简化。
  2. 需要减轻显示负担时，手动降低“三角面保留比例”，松开滑块后开始生成所选比例的模型。
  3. 查看滑块下方的原始面数、当前显示面数和实际保留比例。目标比例是近似值，小网格或复杂结构可能无法精确达到目标。
  4. 设回 100% 恢复完整原始网格。简化不会改写原始导出数组。

分割标签

  • 分割对象按标签着色，标签列表显示完整前景体素统计。
  • 点击某个标签会按其局部范围重新生成表面；点击“显示全部”返回概览。
  • 很小的标签可能在概览采样中不可见。应先单独选择标签，再按需提高预览精度。
  • 分割表面来自所选精度的体素边界，因此可能有台阶。其保留比例相对当前采样生成的表面计算。

选择显示精度

数据类型精度控制
原始网格三角面保留比例，默认 100%
体数据快速 / 均衡 / 精细采样；不改变源数组
分割表面采样精度，以及相对当前表面的保留比例
测量表和完整标签统计来自原始数据。不要使用简化后的表面或采样切片代替原始数据进行定量测量。

07　实时剖面与正交正视

移动剖面时，无需松开滑块：剖切模型、参考平面和体数据切片会随输入同步更新。

操作步骤

  1. 在右侧“剖面视图”勾选“启用”。选择“剖切模型 + 截面”或“仅显示截面”。
  2. 拖动“方位角”和“仰角”改变剖面方向；拖动“剖面距离”改变位置。也可在数值框输入精确距离。
  3. 点击“反向剖切”改变保留的一侧；点击“回到中心”将距离设为 0。可关闭“参考平面”以便观察。
  4. 点击“正对剖面”，使视线沿剖面法线并使用正交投影。保持此状态移动剖面时，视点跟随剖面且保留缩放。
  5. 拖动三维画面、切换视角或开启旋转会退出自动跟随；再次点击“正对剖面”即可恢复。

角度与距离含义

参数含义
方位角剖面法线在 XY 平面中的方向，范围 -180° 到 180°
仰角法线与 XY 平面的夹角，范围 -90° 到 90°
距离从模型包围盒中心沿法线移动的有符号距离
0° / 0°法线沿 +X，剖面平行 YZ
90° / 0°法线沿 +Y，剖面平行 XZ
0° / 90°法线沿 +Z，剖面平行 XY

截面显示

网格和分割表面支持“仅截线”“填充”“填充 + 轮廓”（默认），填充不透明度为 10–100%。闭合截面通过校验后填充并保留孔洞；开放、自交或过于复杂的轮廓保留截线并提示。填充仅影响显示，不改写源数据或 PLY。拖动时先显示实时截线，填充在后台补齐；截图前应等待当前填充完成。

体数据剖面显示当前采样纹理的灰度切片，受窗口设置影响。距离沿原始坐标单位计算；“反向剖切”只改变保留侧，不改变距离定义。

08　CT 三切面联动

三个原始二维切面与一个三维定位窗口联动显示。背景和方向标识跟随统一配色，灰度数据保持原始含义。

打开与定位

  1. 选择体数据对象后，默认进入“CT 三切面联动”。顶部“三切面”按钮可切换四窗口与三维投影；右侧显示方式可选择其他体数据模式。
  2. 点击或拖动任一二维切面的十字线，同时改变另两个切面的索引。三维定位平面随移动立即更新，原始切片读取完成后同步替换平面纹理。
  3. 在二维切面内滚动鼠标滚轮，逐张翻动该方向的切片。右侧 X、Y、Z 滑块也可直接定位。所有索引从 0 开始。
  4. 点击切面后可用方向键移动十字线，用 PageUp / PageDown 翻片。三维窗口保持左键旋转、右键平移和滚轮缩放。 标题栏“最大化”放大单个切面，“还原”或 Esc 返回四窗口。

方向与标识

方向切面与显示
XYZ 平面，X 索引固定
YXZ 平面，Y 索引固定
ZXY 平面，Z 索引固定

灰度、读数与截图

窗口下限和上限统一控制三个二维切面和三维定位平面的灰度。切换时间步会读取对应时刻并保留定位索引。底部显示 X/Y/Z 和原始体素值，悬停读数可查看世界坐标。

二维切面直接读取原始分辨率，按体素变换保留实际比例；窗口运算使用 float32，底部读数直接读取源数组。非有限值显示为黑色。单面超过 1677 万像素时提示无法载入，不自动降低分辨率。

点击“截图”预览，再点击“保存 PNG”。四窗口模式保存三个切面与三维定位；最大化时只保存当前切面。需要任意角度剖面时，先切换到三维投影或等值面，再启用“剖面视图”。

X/Y/Z 表示数据坐标轴，不自动推断解剖方向；原始值不自动换算为 HU。体数据三切面显示灰度切片，三角网格三切面显示截线，分割表面继续使用任意角度剖面。

09　网格三切面与统一配色

STL 与 ORS 三角网格也可以联动查看三个方向的截线。三维和三切面共享同一套可保存主题。

网格三切面

  1. 选择三角网格对象，点击顶部“三切面”，进入三个截线窗口和三维定位窗口。再次点击可回到单独三维视图。
  2. 点击或拖动二维窗口中的十字线，同步移动另外两个切面。滚轮改变当前切面的位置；方向键移动十字线，PageUp / PageDown 移动当前切面。
  3. 右侧 X/Y/Z 滑块与精确坐标框使用原始网格坐标单位。“回到中心”恢复模型包围盒中心。平面网格中没有厚度的方向保持固定。
  4. 三维定位即时更新，二维截线持续刷新，填充在后台补齐。标题栏“最大化”单独放大该切面，“还原”或 Esc 返回四窗口。截图保存当前窗口布局。

网格与截线的关系

默认对全部原始三角面计算截线，不自动降低面数。手动调整三角面保留比例后，截线跟随当前显示网格；恢复 100% 使用原始网格。

截面可选择仅截线、填充或填充 + 轮廓。仅填充通过校验的闭合轮廓，保留孔洞；不生成真实灰度体素，不改写网格或 PLY。单面超过 200 万线段时明确提示，不截断或自动简化。

统一配色

方案效果
黑白暗色背景、灰白模型与截线，实线 / 虚线区分方向
浅色浅色背景、灰色模型、深色方向标识
深蓝（默认）深蓝背景、冷色模型、彩色方向标识

使用右上角“统一配色”立即切换。背景、模型材质、定位平面、截线和截图同时更新；切换三维与三切面时保持一致，后续启动记住所选主题。CT 灰度、分割标签颜色和标量色谱保留各自的数据含义。

网格坐标不自动推断单位，STL 通常没有单位信息。浏览器几何使用 float32，原始导出数组保持源精度。任意角度剖面可在退出三切面后继续使用。

10　切面缩放、填充与实时刷新

三个二维切面可分别缩放；网格截面可显示内部区域，并保留孔洞和来源边界。

独立缩放、平移与最大化

  1. 拖动各二维窗口底部的缩放滑块，设置 25–800%。100% 表示适应当前窗口，不是物理尺寸或原始像素一比一。
  2. 右键拖动切面可平移；“定位”将十字线移到视窗中心；“适应”恢复该窗口 100% 并显示完整切面。
  3. 缩放不会改变切面位置、其他窗口比例或网格简化比例。移动切面、切换时间步或三维 / 三切面模式时保留比例，重新选择对象后恢复适应。
  4. 每个切面标题栏都有“最大化”。点击“还原”或按 Esc 返回四窗口，位置、缩放和平移保留。退出三切面或切换对象时恢复四窗口；最大化时截图仅保存当前切面。

网格截面填充

显示方式效果
仅截线显示原始计算得到的截线
填充显示闭合区域，内部孔洞保持空白
填充 + 轮廓（默认）填充闭合区域并叠加边界轮廓

右侧“填充不透明度”支持 10–100%。二维切面与三维定位平面同步应用显示方式；截图保留当前缩放、平移和填充效果。

开放、分叉、自交、重叠或校验过于复杂的截面不会强行填充，而会回退为完整截线并显示原因。填充依据当前切面的闭合轮廓，不保证整个网格水密，不改变源网格或导出 PLY。

移动时持续刷新

拖动过程中会持续提交并显示切片 / 截线结果，不等待鼠标松开。大网格首次使用需要建立空间索引，索引不减少三角面；移动后优先更新截线，再补齐填充。

如果计算暂时落后，窗口标题会标明当前实际显示的位置。最新结果到达后自动替换；性能取决于网格规模、存储和硬件。保存截图前应等待当前切面完成更新。

填充使用当前显示网格：默认全部原始三角面；只有手动修改保留比例才使用简化几何。不会为了缩放或实时刷新而自动简化。

12　常见问题与操作建议

先检查对象类型、显示状态和数据范围，再判断是否是解析问题。

剖面看不到内容

剖面可能位于结构外部。点击“回到中心”，切换到“剖切模型 + 截面”，再缓慢移动距离。若模型包围盒中心本身没有前景结构，需要继续寻找有数据的位置。

拖动大模型仍不够流畅

实时更新并不保证所有显卡达到固定帧率。原始大网格和实时截线都需要显存与计算资源。可以关闭线框、参考网格或包围盒；如需简化，应自行调整保留比例，软件不会自动降低面数。初次启用网格剖面还需要准备后台截线数据。

模型像素化或有台阶

三维体数据投影和分割使用采样预览，分割边界也可能保留体素台阶。可以提高精度或单独选择标签观察。显示外观不代表源数组已丢失精度。

导入失败或没有可显示对象

确认文件格式、文件完整性和磁盘可用空间。ORS 中未实现的容器变体或对象类型可能无法显示；原始记录完整提取也不等于所有工作区语义都已恢复。查看导入任务目录中的 import.json、parser.log 和 result/job.json 可了解具体状态。

无法打开三维画面

确认桌面启动窗口仍在运行，并从该窗口重新打开界面。浏览器需要 WebGL 2。更换支持 WebGL 2 的浏览器或检查显卡驱动与浏览器图形加速设置；页面显示错误时不要将空白画面视为解析成功。

输入距离或改变视角后行为不同

距离会被限制在当前方向的模型包围范围内。数值框正在输入时保留输入格式，确认输入后显示规范数值。进入正视模式后用滚轮缩放可保持跟随；手动拖动画面或切换视角后，应再次点击“正对剖面”。

13　命令行与输出文件

需要批量提取或在其他程序中读取结果时，可使用 Python 命令行入口。

源码环境

需要 Python 3.14 或更新版本。创建并激活虚拟环境后，在源码目录安装项目。Windows 免安装版已自带运行环境，不需要执行此步骤。

python -m pip install .
ors-viewer

启动本地服务

ors-viewer --headless --open --port 8769
ors-viewer --state-dir ./viewer-data --data ./extracted/data

独立提取

输出目录必须不存在。不加 --dense-labels 时优先保存稀疏标签区间；--dense-limit-gib 设置稠密标签输出的空间上限。

ors-extract sample.ORSSession --output extracted
ors-extract sample.ORSObject --output extracted --dense-labels --dense-limit-gib 2
