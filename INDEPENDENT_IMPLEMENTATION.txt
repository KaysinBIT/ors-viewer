适用版本：0.8.1

公开说明

ORS Viewer 是独立开发的文件解析与可视化工具，用于读取用户依法持有或经授权处理的 .ORSSession、.ORSObject 等数据文件。当前发布版本采用本项目的解析代码及已列明许可的通用开源依赖，未集成、调用、链接或随包分发 Dragonfly 及其权利人的官方应用程序、SDK、ORSModel/ORSServiceClass 库、专有动态库、插件或授权模块；运行和数据提取不需要安装或启动 Dragonfly。上述格式名称仅用于标明兼容的输入类型，相关商标及其他权利仍归各自权利人所有，本项目与其不存在隶属、合作、授权或认可关系。项目许可证仅适用于本项目有权许可的代码，不授予第三方软件、格式相关专利、样本数据或用户文件的额外权利。本项目不提供激活、许可校验绕过或访问控制破解功能；使用者仍应确保文件来源及处理用途合法，并遵守适用法律和实际适用的合同约定。本说明披露实现方式与权利边界，不构成不侵权保证。

技术实现范围

1. 文件解析由 ors_binary.py、ors_decode.py 和 ors_extract.py 完成；体数据、标签、网格及测量表处理使用 Python 标准库和 NumPy。压缩数据通过 Python 的 compression.zstd 处理。
2. 本地服务由 Python 实现；三维显示使用 Three.js，桌面启动窗口使用 Python/Tcl/Tk。Windows 发行包由 PyInstaller 打包通用运行环境。
3. 第三方依赖及许可证列于 THIRD_PARTY_NOTICES.md 和发行包 licenses 目录。这些是通用依赖，不是 Dragonfly 官方组件。
4. 格式解析可能识别文件中的 Cxv 等类型名称及其他元数据字符串。这些名称用于解释输入文件，不表示导入、执行或重新分发同名官方类库。
5. 程序使用公开格式说明及数据文件中的结构信息进行兼容性实现。查阅公开资料与集成官方组件是不同事项；不将公开文档的可访问性视为对其代码、图片或全文的再发布许可。
6. 默认发行包仅含程序生成的四面体示例，不包含第三方 ORS 样本、用户数据、官方安装包、SDK 或许可文件。输入文件中原有的归属与权利信息不因本项目的许可证而改变。
