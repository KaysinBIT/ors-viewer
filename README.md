# ORS Viewer

独立的 ORSSession 解析与三维查看软件。支持体数据、分割标签、三角网格和测量表，全程在本机运行，无需安装 Dragonfly。

使用说明：[PDF 说明书](viewer/web/manual.pdf) · [网页版说明书源文件](viewer/web/manual.html)。运行软件后也可点击右上角“使用说明”，离线阅读全部操作步骤。

当前源码为 1.2.0rc1 候选版，新增整个数据集姿态对齐；公开稳定版仍为 1.1.0。候选版尚待浏览器交互与视觉验收。

## 功能

- 导入 `.ORSSession`、`.ORSObject`、二进制/ASCII `.STL` 和三维/四维数值 `.NPY`。
- 本地文件浏览器支持文件、文件夹选择和新建数据目录，路径由选择结果自动填写。
- 启动窗口直接设置端口和数据目录，手动启动服务并打开网页；首次目录默认为程序所在文件夹，后续记住选择。
- 端口默认 0（自动分配），也可设置 1–65535；目录选择使用文件夹按钮，启动失败会在窗口内提示。
- 自动提取支持的对象类型，保存原始记录、元数据、数值数组、网格和测量表。
- 原始网格默认保留全部顶点和三角面，不自动简化。手动调整保留比例后才简化，设回 100% 恢复原始网格，并显示实际面数。
- 整个数据集共用旋转中心与姿态：XYZ 角度、±90°、参考面或三点自动对齐、固定 XYZ 切面、单独保存与恢复。
- 对齐 CT 切面使用线性插值，分割切面使用最近邻并保留完整标签 ID。原始数据、测量表和源坐标导出保持不变。
- CT 三切面联动：三个原始二维切面 + 三维定位，十字线拖动、滚轮翻片、X/Y/Z 滑块、统一窗口与时间步、原始体素读数、四窗口截图。
- 三角网格支持三切面：三个轴向截面与三维定位联动，支持十字线拖动、滚轮移动、精确坐标和四窗口截图。
- 每个二维切面独立缩放 25–800%，提供右键平移、定位十字线和适应窗口。
- X/Y/Z 切面可分别最大化，支持按钮或 Esc 还原；保留切面位置、缩放和平移，截图遵循当前布局。
- 任意角度剖面支持闭合截面填充、保留孔洞，可选择仅截线、填充或填充 + 轮廓并调整透明度。
- 网格截面支持仅截线、填充、填充 + 轮廓，填充不透明度可调并保留孔洞。
- 三维与三切面共用黑白、浅色、深蓝主题，默认黑白；统一背景、模型材质、截线与方向标识，选择自动保存。
- 体数据还支持最大强度投影、等值面、三维切片定位和任意角度灰度切片。
- 分割标签着色、单标签局部显示、完整体素统计。
- 可调剖面方位角、仰角和距离，支持反向剖切、仅显示截面及沿法线的正交正视。
- 拖动剖面时同步更新三维画面，后台计算精确截线；正视模式移动剖面时保持缩放。
- 测量表分页、单位与缩放、CSV 下载、逐顶点标量着色。
- 三维旋转、平移、缩放、居中、线框、包围盒、截图及显示网格 PLY 导出。
- 后台导入任务、结果持久化、桌面启动窗口、命令行提取。

## Windows 免安装版

1. 从 Releases 下载 `ORSViewer-1.1.0-Windows-x64.zip`。
2. 完整解压，保持 `ORSViewer.exe` 与 `_internal` 目录在一起。
3. 双击 `ORSViewer.exe`。启动窗口不会自动打开网页。检查端口（0 为自动分配）和数据目录，点击“选择文件夹…”可修改目录。
4. 点击“保存并启动服务”，显示本地网址后，再手动点击“打开三维界面”。
5. 在三维界面点击“导入文件”，使用“本地文件路径”旁的“选择文件”按钮选取文件，无需手动输入路径。

发行包包含 Python 运行环境，不需要单独安装 Python 或 Dragonfly。三维界面需要支持 WebGL 2 的浏览器。大文件可通过“选择文件”直接读取本地路径，避免上传副本。

首次数据目录默认为 `ORSViewer.exe` 所在文件夹（源码运行时为项目目录）；已有配置会沿用上次选择。启动时检查目录可写性，失败后可重新选择。解析输出、缓存、日志、示例和运行信息分别存放在数据目录内的 `imported`、`cache`、`logs`、`example` 和 `runtime` 文件夹中。

运行后可点击“停止服务并修改”重新设置端口和目录，再启动服务并手动打开页面。停止服务或关闭启动窗口会中断未完成任务，已有输出保留。更换目录不会移动或删除旧数据。Windows 的 `%LOCALAPPDATA%/ORSViewer/settings.json` 保存目录、端口、主题及按数据集路径区分的对齐偏好。

1.1.0 为已发布正式版。1.2.0rc1 为本地候选测试版本；自动化验证覆盖共享变换、插值、标签、导出不变与视图切换，浏览器视觉验收尚未完成。

## 从源码运行

需要 Python 3.14 或更新版本：

```sh
python -m venv .venv
# 激活虚拟环境后：
python -m pip install .
ors-viewer
```

仅启动本地服务：

```sh
ors-viewer --headless --open --port 8769
```

指定运行数据目录或打开已有解析结果：

```sh
ors-viewer --state-dir ./viewer-data --data ./extracted/data
```

`--state-dir` 仅指定本次启动的数据目录，不覆盖已保存设置。需要重新选择默认目录时运行 `ors-viewer --choose-data-dir`。无界面批处理应使用 `--state-dir`，或事先完成数据目录设置；`--settings-file` 可指定独立配置文件。

命令行提取全部支持的对象：

```sh
ors-extract sample.ORSSession --output extracted
ors-extract sample.ORSObject --output extracted --dense-labels
```

输出目录必须不存在。省略 `--dense-labels` 时，分割优先保存为稀疏区间，避免大体积稠密数组。`--dense-limit-gib` 控制稠密标签输出上限。

## 数据与显示

| 数据 | 保存形式 | 查看功能 |
| --- | --- | --- |
| 体数据 | 原始位宽 NPY，TZYX | 投影、等值面、切片、窗口、时间步 |
| 分割 | 稀疏标签区间、可选稠密 NPY | 多标签表面、单标签显示、体素统计 |
| 网格 | 顶点、三角面、法线、UV、PLY | 完整网格、手动简化、线框、剖切、三切面 |
| 测量 | NPY/JSON 列、适用时 CSV | 分页、单位和缩放、标量映射 |
| 容器 | XML、原始记录、清单、哈希 | 完整性和未解释记录保留 |

原始网格的 100% 模式不丢弃、合并或去重三角面。浏览器坐标使用 float32；原始导出数组保留源精度。手动简化使用顶点聚类，目标比例可能与实际面数略有差异。大型完整网格需要相应的内存和显存，程序不会自动降低面数。

CT 二维切片直接读取原始分辨率，按体素空间变换显示比例，窗口运算使用 float32；底部定位读数直接读取原始数组，整数读数保留完整精度。索引从 0 开始，方向按数据 X/Y/Z 轴显示，不自动推断解剖方向或 HU。单面超过 1677 万像素时明确提示，不自动降采样。

三维体数据投影、任意剖面与分割表面使用界面所选采样精度；三维体纹理为 8 位。CT 定位平面移动后先使用快速纹理，原始切片读取完成后同步替换；超出显卡纹理尺寸限制的定位平面保留快速纹理，二维原始切片不受该显卡限制。分割保留比例相对当前采样表面计算。网格和分割表面的任意剖面支持显示用截面填充，开放或无法验证的轮廓保留截线；体数据剖面显示采样灰度。显示网格 PLY 导出不写入显示用的剖切操作，也不包含测量表或标签属性。定量分析应使用原始数组和测量数据。

支持 ORSD、ORSZ 与 CAIFZ 的已实现容器结构。未支持的对象语义不作推测，原始记录保留供其他处理使用。软件不恢复完整 Dragonfly 工作区的全部渲染状态、历史操作或父节点关系。NPY 按 ZYX/TZYX 解释且默认体素间距为 1；STL 不包含物理单位。

## 本地运行

服务只监听 `127.0.0.1`。网页资源随软件提供，不依赖外部 CDN；导入文件不会上传到远程服务器。文件选择导入上限为 64 GiB，更大的文件使用本地路径导入。解析结果、缓存和运行日志保存在运行数据目录。

## 网格三切面与统一配色

选择 STL 或 ORS 三角网格对象，点击顶部“三切面”进入三个二维截线与三维定位联动的四窗口。拖动十字线、使用滚轮或右侧 X/Y/Z 滑块移动切面；精确坐标框使用网格原始单位。“回到中心”恢复包围盒中心。网格三切面与任意角度剖面分别操作，退出三切面后可继续使用任意剖面。

截线由当前显示网格在后台计算，空间索引只筛除不相交的包围盒，不减少三角面。移动时定位平面立即更新，二维窗口持续显示最新完成的截线，填充在后台补齐，不等待松开鼠标。计算未追上操作时，标题标明实际显示位置；原始体数据切片同样持续刷新。默认使用全部原始三角面；只有手动降低保留比例才使用对应简化网格，恢复 100% 即恢复原始网格。网格截面可选择仅截线、填充或填充 + 轮廓（默认），填充不透明度为 10–100%。仅对闭合且通过拓扑校验的轮廓填充，内环保留为空洞；共面三角片会在显示用填充中移除内部共享边。开放、分叉、自交、重叠或超出验证限额的截面回退为完整截线，并给出提示。填充不等于整网格水密性认证，不生成真实灰度体素、不修改源网格，也不写入 PLY 导出。单切面超过 200 万线段时明确提示，既不截断结果，也不自动简化。浏览器几何仍采用 float32，原始导出精度不变。

每个二维窗口下方的缩放滑块可独立设置 25–800%；100% 表示适应当前窗口。右键拖动平移，“定位”居中十字线，“适应”恢复该切面 100%。移动切面、切换时间步与切换显示模式时保留比例；重新选择对象会恢复适应窗口。缩放不改变切面位置或简化比例。截图保留各窗口的缩放、平移和填充外观。标题栏“最大化”可单独放大一个切面；“还原”或 Esc 返回四窗口。最大化时截图仅保存当前切面；退出三切面或切换对象会还原布局。

右上角“统一配色”对单独三维视图与四窗口同时生效，并保存到本机设置。黑白与浅色主题用灰阶和实线/虚线区分方向，深蓝主题使用彩色方向标识。CT 灰度数据、标签颜色及标量色谱保持各自的数据含义。

## 网页端口设置

桌面启动窗口直接填写端口：`0` 表示自动分配，`1–65535` 表示指定端口。点击“保存并启动服务”成功后，手动点击“打开三维界面”。端口被占用时在窗口内提示，不会自动改用其他端口；可改填 `0` 后重试。运行后先“停止服务并修改”再调整，停止操作会中断未完成任务。

网页右上角“端口设置”仍可保存下次启动的端口，当前任务不受影响。无界面模式省略 `--port` 时沿用已保存设置，已保存端口不可用时临时自动分配并提示。`--port 8769` 仅覆盖本次启动，`--port 0` 本次自动分配；显式指定端口不可用时报错。监听地址始终为 `127.0.0.1`。

## 代码结构与兼容性

1.0.0 的重构以 v0.9.1RC2 的可观察行为为兼容基准。1.1.0 在此基础上新增任意剖面填充和单切面最大化，不修改源数据或导出网格。

| 模块 | 职责 |
| --- | --- |
| `viewer/web/view-controls.js` | 统一网格、体数据的 3D / 三切面状态同步 |
| `viewer/web/data-client.js` | JSON 与二进制预览请求，保留原有错误和取消行为 |
| `viewer/web/export-ply.js` | 原有 PLY 二进制格式的生成 |
| `viewer/web/ui-constants.js` | 现有分页数量、百分比及等待时间的命名常量 |
| `viewer/web/app.js` | 对象选择、预览请求、结果呈现和测量表的协调 |
| `viewer/server.py` | 分离对象响应、设置、上传与 JSON 请求读取，保留状态码、限制和授权检查 |

回归测试包含重构前捕获的 68 组视图状态基准与 PLY 字节基准；测试不需要 Dragonfly。运行 Python 测试及 `tests/test_*.mjs`，或查看 Windows / Linux 持续集成结果。

显示仍使用原有精度与数据格式；版本号、发行说明和代码组织变更不扩大专有格式的解析范围。体数据退出三切面仍切换到最大强度投影，原始网格仍默认保留 100%。

## 任意剖面的截面填充

选择网格或分割对象，启用右侧“剖面视图”，可在“截面显示”选择仅截线、填充、填充 + 轮廓，填充不透明度为 10–100%。默认采用填充 + 轮廓。与“仅显示截面”和“正对剖面”配合，可直接查看填充的任意角度截面。

仅对通过校验的闭合轮廓填充，保留孔洞；开放、分叉、自交、重叠或过于复杂的轮廓回退为截线并给出提示。移动剖面时立即隐藏过期填充，实时截线先更新，当前填充随后补齐。填充跟随统一配色，仅影响显示，不修改源网格或 PLY 导出。
